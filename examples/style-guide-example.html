17 — Animation System — entrance + interactive patterns

Three files power all deck animations. Import in this order when a slide needs motion:

Slide entrance
animation.css
Defines data-animate="fade-up|scale-in|fade-in" classes and the anim-in trigger state. Pure CSS — no JS required for basic entrance.
Slide JS engine
animation.js
Watches .slide for .active class changes. On activate: fires entrance animations with per-element data-anim-delay stagger. Part 2 exposes: typeInto, countUp, fillBar, fillRing, streamItem, reveal, makeSequence.
Interactive patterns
animation-interactions.css
8 interactive patterns with state classes: typewriter chat, flow/decision tree, data pipeline, progress bar, score ring, stream list, checklist, pulse ring. Play/reset button styles included.
data-animate="fade-up"
Slides up 12px while fading in. Default entrance for eyebrows, titles, body copy.
data-animate="scale-in"
Scales from 0.94 while fading in. Use for cards, KPI tiles, stat elements.
data-animate="fade-in"
Opacity only — no movement. Use for compare table rows or any element that shouldn't shift.
data-anim-delay="240"
Per-element delay in ms. Stagger cards at +60ms increments. Hero KPIs: 300–480ms.
View all 8 interactive patterns → animation-demo.html

All 8 interactive animation patterns are demonstrated with live play/reset controls in animation-demo.html. Import animation-interactions.css and animation.js together — the CSS defines the state classes, JS provides the sequencing utilities.

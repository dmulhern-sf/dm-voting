How It Works

Each layer builds on the one below. The AI handles the design. The MCP layer handles the execution. Your team owns the outcome.
4 layers
SF Composer — AI Journey Architecture
01
Claude AI
Journey Intelligence
Receives a natural language brief — use case, audience, stack selection, channels — and generates a structured, multi-step journey with CX and EX lanes. No templates. No configuration menus. Just a conversation.
02
Canvas Engine
Visual Swimlane Renderer
Renders the AI output as an interactive swimlane canvas — CX row, EX row, and connector row. Each step is clickable, editable, and carries full configuration metadata. The map is the source of truth — not a decoration of it.
03
Stack Configurator
11 Platform Categories
Marketers select their live platforms — Salesforce native, MCP-connected (Shopify, HubSpot, Segment), or agent-orchestrated — before generating. The AI builds the journey using only the tools they actually have. No fictional stack. No vendor assumptions.
04
MCP + Export Layer
Live Execution Bridge
Each journey step exports as an executable artefact — a MuleSoft flow, a Marketing Cloud entry source, an Agentforce action, or a Salesforce Flow. The gap between journey design and journey execution closes to a single click.

Where This Goes
Three extensions that open
the full platform opportunity
The canvas and AI layer are the foundation. These three extensions turn SF Composer from a demo asset into a product-grade journey design system.
EXTENSION 01
MuleSoft live execution bridge
Every journey step with a MCP config path exports as a deployable MuleSoft flow. Journey design and integration design become the same artefact — built once, executed anywhere in the Anypoint platform.
EXTENSION 02
Data Cloud segment activation
Journey entry conditions in the canvas map directly to Data Cloud segment definitions. When a customer's profile triggers the segment, the journey fires — no manual handoff between the design tool and the data platform.
EXTENSION 03
Multi-journey workspace
Teams manage dozens of journeys simultaneously. A workspace layer lets marketers organise journeys by programme, campaign, or lifecycle stage — with shared stack configuration and reusable step templates across all of them.
